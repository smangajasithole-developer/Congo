# Congo – DJ & Producer Profile Website

Congo is a DJ and music producer profile website developed to establish an online presence and showcase the artist's profile, music-related content, and professional information.

🌐 **Live Website:** [https://djcongo.pythonanywhere.com](https://djcongo.pythonanywhere.com)

---

## Features

- **Artist Profile:** Presents the DJ and producer's profile and background.
- **Music Showcase:** Provides a platform for presenting music-related content.
- **Responsive Design:** Supports different screen sizes and devices.
- **Website Presentation:** Uses a clean layout to showcase the artist's identity and information.
